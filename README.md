# Cafe Website Template

Reusable cafe/restaurant website master template.

Planned: premium landing page, menu, cart, WhatsApp ordering, reviews, gallery, location, checkout, and future Firebase admin panel.

## Asset setup
All supplied THE COZY CUP assets are included under `public/images/` and are referenced using normalized web-safe filenames. The Cozy Club Sandwich currently reuses the supplied Smoky Chicken Panini image because no separate Cozy Club Sandwich asset was provided.

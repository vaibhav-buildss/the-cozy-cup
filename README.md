# ☕ THE COZY CUP

> **Where Every Sip Feels Like Home.**

THE COZY CUP is a modern, responsive café website designed to create a warm and welcoming digital experience for the café. It combines a cozy visual identity with an interactive menu, café showcase, customer experience sections, shopping cart, checkout, and online ordering.

## ✨ Features

- 🏠 Modern café landing page
- ☕ Interactive food & beverage menu
- 🔎 Menu search and category filtering
- 🛒 Shopping cart functionality
- 📦 Checkout and order flow
- 💬 WhatsApp ordering integration
- 🖼️ Café gallery
- ⭐ Customer testimonials
- 📍 Location and contact information
- 📱 Fully responsive design
- ✨ Smooth animations and transitions
- 💾 Cart persistence using LocalStorage

## 🎨 Design

The website uses a warm and modern café-inspired visual identity with:

- Coffee Brown
- Cream
- Sage Green
- Dark Charcoal
- Soft Golden accents

The overall experience is designed around the idea of THE COZY CUP feeling like a **second home** — warm, relaxed, social, and inviting.

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- JavaScript
- LocalStorage
- WhatsApp Ordering
